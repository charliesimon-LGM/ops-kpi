# asset360-kpi — Asset360 Operations Intelligence

A mobile-first hotel operating KPI dashboard featuring executive financial and commercial results, four Flow/Flex categories, expense pressure with a departmental labor breakdown, and departmental diagnostics.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named **`asset360-kpi`**.
2. In the new empty repository, select **uploading an existing file**. Upload **both** `index.html` and `README.md` from this extracted folder. Commit changes.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and Save.
4. Your site URL will be `https://YOUR-USERNAME.github.io/asset360-kpi/`. It can take a few minutes to deploy.

## How to use

- Select YTD or MTD.
- Open expense categories to see budget pressure; labor expands automatically into departmental variances.
- Choose a department for productivity, profit and service details.
- Use **Edit figures** to update raw inputs; derived ratios update automatically.
- Use **Export CSV** for Excel.
- This is a public demonstration using modeled data, not actual hotel financial information.

## Data and privacy

All entered figures are saved only in your browser. They do not sync across devices. This static app has no authentication, backend or live accounting integration. Do not use for confidential financials.
